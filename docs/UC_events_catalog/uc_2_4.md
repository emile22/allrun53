# UC 2.4 - Real-time Energy Metering of Virtualised or Cloud-native Network Functions

Topology: T5 EDGE. The host meter is operational YANG data; virtual-function allocation and attribution remain scenario metadata.

| Event | Name                             | Observable fallback                       |
| ----- | -------------------------------- | ----------------------------------------- |
| U4-0  | HOST_AND_VNF_INVENTORY           | Host reading; VNF energy UNKNOWN          |
| U4-1  | HOST_METERING_BASELINE           | Host interval measurement                 |
| U4-2  | VNF_WORKLOAD_INCREASED           | Host interval changes; no per-VNF counter |
| U4-3  | HOST_ENERGY_DELTA_OBSERVED       | Host interval measurement                 |
| U4-4  | PER_VNF_ATTRIBUTION_GAP_RECORDED | VNF energy UNKNOWN                        |
| U4-5  | HOST_ALLOCATION_CHANGED          | Allocation is scenario metadata           |
| U4-6  | HOST_METERING_REVALIDATED        | Host measurement remains available        |
| U4-7  | HOST_INTERVAL_CLOSED             | Host counter only                         |

Gap: `UC2.4/PER_VNF_ATTRIBUTION`. Detailed evidence is in [fill_in_gaps.md](../fill_in_gaps.md).
